# Instalar no smartphone

1. Publique esta pasta no Vercel.
2. Abra a URL no Chrome Android.
3. Toque no menu ⋮.
4. Escolha **Instalar app** ou **Adicionar à tela inicial**.
5. Após o primeiro carregamento, a interface principal fica disponível offline.

Observação: o relatório pode ser salvo em PDF pelo recurso de impressão do navegador.
